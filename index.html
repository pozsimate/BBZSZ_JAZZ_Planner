Students

One row per student, exactly as in the STUDENTS sheet. The instrument, class, and seven subject-group columns are dropdowns sourced from the Reference tables tab — each one only lists groups whose TYPE matches that column (e.g. RHIMPR only offers RHYTHM-type groups), so you can't accidentally assign the wrong kind of group. Pick a name and the underlying ID is stored automatically. Blank group columns mean that student isn't enrolled in that subject.

Lesson groups

One row per teachable group (the LESSON sheet). GROUP and TEACHER are dropdowns from the Reference tables; the scheduler pulls every student whose matching subject-group field equals that group, then looks for a slot where the teacher and every one of those students are free. Tick ROOM 321 if the lesson has to happen in that room — the scheduler then also makes sure no two ROOM 321 lessons ever overlap, no matter which teachers they belong to. Fill in FIXED DAY / FIXED START / FIXED END to pin this lesson to an exact slot — no searching, no negotiating: the scheduler places it there first, before anything else, and only fails it if that exact slot is already physically taken by someone.

Teacher availability

One row per teacher/day, exactly as in the TEACHER availability sheet. Leave START or END blank to default to the school-day bounds (08:00–20:00). TYPE ranks how strongly the slot should be used: AVAILABLE / PREFERRED beat FALLBACK, which beats CANDIDATE. AVOID excludes that day entirely, even if another row lists it.

Class Reservations

One row per reserved (busy) block for a class/day — the opposite of an availability sheet, matching the CLASS_CONST tab. Each row says "this class is tied up with regular schoolwork between START and END"; whatever's left over that day (within 08:00–20:00) is what's actually free for a jazz lesson. 1j/2j/3j have no rows at all in the source, so they're treated as free the entire day. A class/day with no rows is always treated as free all day.

Reference tables

The four lookup sheets (TEACHER_ID, CLASSID, GROUP, INSTR). These are exactly what feed every dropdown elsewhere in the app — add, rename, or remove an ID here and it's reflected everywhere the next time that tab renders. On Classes, JCLASS TYPE marks which classes are interchangeable from a jazz-scheduling point of view (e.g. 9a/9b/9c all default to "9") — the scheduler uses it to try to cluster same-grade lessons back to back, even across different teachers. On Groups, TYPE (IMPR / VOC / JAZZTHEO / SOLF / JAZZHIS / AC / RHYTHM) determines which Students column that group can be picked in. On Instruments, TYPE (sol / acc / bass / drum) marks each instrument's role, used by the Bands tab to build combos. On Teachers, only a gap of exactly BREAK MIN minutes is ever allowed for that teacher, and only up to BREAK COUNT times per day — not "up to" that length, not combined into a bigger one (e.g. 45 × 2 means exactly two 45-minute gaps, never one 90-minute gap or a 30-minute one). Leave both at 0 for the default: no gap ever, and the scheduler still minimizes gaps for every teacher regardless of these settings. BAND QUOTA sets how many band rehearsals that teacher can be automatically matched to when the Timetable is generated.

Generate

Builds the weekly schedule from every tab above, teacher by teacher: for each teacher, their available days are grouped by rank (PREFERRED/AVAILABLE days together, then FALLBACK, then CANDIDATE), and within each group the remaining lessons are split as evenly as possible across those days — so a teacher offering three preferred days gets their lessons spread across all three instead of piled onto the first one. Within each day, lessons are still packed as tightly as possible (this is what lets two lessons effectively "swap places" so there's no wasted gap). Rules: by default two lessons of the same teacher on the same day may never have a gap between them — unless that teacher has a BREAK MIN / BREAK COUNT set in Reference tables → Teachers, in which case up to that many gaps of up to that many minutes are allowed per day. Two lessons both flagged ROOM 321 may never overlap in time, regardless of teacher. As a soft best-effort nudge, a lesson also tries to start right next to another lesson (any teacher) that shares a JCLASS TYPE that day, so same-grade lessons cluster together with minimal gaps. Bands (from the Bands tab) are scheduled in their own pass: first a free time slot is found from their members' availability alone, then a teacher is matched to that slot afterward based on remaining BAND QUOTA (Reference tables → Teachers) — unless you set a manual "Teacher override" on that band, in which case it's scheduled the normal teacher-first way instead. Whatever doesn't fit anywhere is left unresolved. Each click tries up to 15 slightly different valid layouts and keeps every distinct one it finds — use the Solution dropdown below to browse them, not just the automatically best-scoring one. Clicking Generate again never throws away what was already found: it keeps adding to the same pool of solutions, so pressing it repeatedly can only find the same result or a better one — never a worse one — as long as nothing on the other tabs has changed since your last click. Once you're happy with a solution, click ✓ Accept this schedule: it's saved into the database as the current timetable (so it's included next time you export "Save all edits"), and every band's assigned teacher gets written back into the Bands tab's "Teacher override" dropdown, matching exactly who ended up with it.

    Generate bands

    Builds small combos out of the students: every band gets at least one BASS, one DRUM, one ACC (guitar/piano), and one SOL (vocal/trump/sax/violin) player, sourced from the Instruments TYPE column. Priority 1: a band's members share the same JCLASS TYPE (grade) wherever possible. Priority 2: nobody is left out — bass/drum players (the scarce roles) may appear in up to two bands if there simply aren't enough to go around, and every extra guitar/piano/vocal/horn player gets placed as an additional member somewhere. Bands aim for 4–5 people, occasionally 6 when the numbers force it. Students with no CLASS assigned are left out of every band on purpose (there's no grade to match them against). Once generated, every band is fully editable: set its rehearsal duration, toggle Room 321 (locked on by default — untick it if that band doesn't need the room), remove a member with the ✕, or add anyone with the "+ Add student…" dropdown. Anyone playing in two bands is highlighted yellow. Use + Add band manually to start a completely empty band and hand-pick every member yourself — works even before you've generated anything, and existing bands are left untouched. Delete a whole band with the ✕ next to its title. Teachers aren't picked here — leave "Teacher override" on "—" and the Timetable finds each band a free time slot from its members' availability first, then matches a teacher afterward based on BAND QUOTA (Reference tables → Teachers) and who's actually free at that exact time. Only set the override dropdown if you want to force a specific band to a specific teacher instead.
